Linux directory structure

Overview

The Linux Foundation maintains the Filesystem Hierarchy Standard (FHS), which defines the directory structure and purpose of directories in Linux distributions. This standardization ensures a consistent directory layout across nearly all Linux distributions.

Directory Structure

/ – Root Directory

Everything in Linux—all files and directories—is located under the root directory represented by /. The directory structure resembles a plant's root system.

/bin – Binaries

Contains executable files of basic shell commands like ls, cp, and cd. Programs are typically in binary format and accessible by all users in the Linux system.

/dev – Device Files

Contains special virtual files relating to devices. These files are not physically stored on the disk.

Notable examples:

  • /dev/null - Discards any data sent to it
  • /dev/zero - Contains an infinite sequence of zeros
  • /dev/random - Contains an infinite sequence of random values

/etc – Configuration Files

Contains core system configuration files used primarily by administrators and services, such as password files and networking configuration. Modify files here to change system settings like hostname.

/usr – User Binaries and Program Data

Contains executable files, libraries, and source code for most system programs. Most files are read-only for normal users.

  • /usr/bin - Basic user commands
  • /usr/sbin - Additional administrator commands
  • /usr/lib - System libraries
  • /usr/share - Documentation and common libraries (e.g., /usr/share/man for manual pages)

/home – User Personal Data

Contains personal directories for users, including their data and user-specific configuration files.

When creating a user (e.g., Alice or Bob), a home directory is created at /home/alice or /home/bob. Users cannot access each other's home directories by default due to file permissions.

/lib – Shared Libraries

Contains libraries (reusable code) needed by binaries in /bin and /sbin. Libraries for /usr/bin and /usr/sbin binaries are located in /usr/lib.

/sbin – System Binaries

Similar to /bin, but contains binaries that can only be run by root or sudo users. The 's' stands for 'super' or 'sudo'.

/tmp – Temporary Files

Stores temporary files for applications and users. Contents are deleted on system restart, and some systems automatically delete old files. Do not store important data here.

/var – Variable Data Files

Stores runtime information including system logs, user tracking, caches, and other files created by system programs. Files are not automatically cleaned, making this useful for system administrators to review system behavior (e.g., /var/log/wtmp for login history).

/boot – Boot Files

Contains kernel files, boot images, and bootloader files (LILO and GRUB). Often recommended to reside on a partition at the beginning of the disk.

/proc – Process and Kernel Files

Contains information about currently running processes and kernel parameters. Used by various tools to obtain runtime system information (e.g., /proc/cpuinfo for processor information, /proc/meminfo for memory usage).

/opt – Optional Software

Used for installing and storing third-party application files not available from the distribution's repository. Software code is typically kept in /opt with binary files linked to /bin for all users to access.

/root – Root User Home Directory

The home directory for the root user, located at /root (not /home/root). Do not confuse with the root directory (/).

/media – Removable Media Mount Point

Automatically created directories for removable media (USB disks, SD cards, DVDs) when connected. Access removable media content from here.

/mnt – Manual Mount Directory

Similar to /media, but used by system administrators to manually mount filesystems rather than automatic mounting.

/srv – Service Data

Contains data for services provided by the system. For example, website data for an HTTP server should be stored here.
